# Product design documentation

- [GoShipKit design contract](DESIGN.md) defines the shared visual language,
  interaction principles, responsive behavior, and platform adaptations.

The contract is authoritative for product UI. External design references are
inspiration only; do not copy another product's brand, logo, proprietary assets,
or layout verbatim. Record durable changes in the design contract before
shipping divergent web, mobile, or desktop patterns.
