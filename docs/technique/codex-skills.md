# Codex skills for GoShipKit

Skills are installed outside this repository. On the current Windows
workstation, the main locations are:

- user and system skills: `C:\Users\PC\.codex\skills\`;
- plugin-provided skills: `C:\Users\PC\.codex\plugins\cache\`;
- GoShipKit skill: `C:\Users\PC\.codex\skills\goshipkit-development\SKILL.md`.

The skills currently visible to Codex are:

- `goshipkit-development` — repository routing and product/security invariants.
- `figma-use` — inspect design context when Figma work is requested.
- `playwright` — verify browser flows and responsive UI.
- `sentry` — diagnose application errors when a Sentry project is connected.
- `gh-address-comments` and `gh-fix-ci` — pull-request maintenance.
- `security-best-practices` and `security-threat-model` — explicit security reviews.
- `pdf` — validate generated stakeholder reports.
- `imagegen` — generate or edit bitmap assets.
- `openai-docs` — official OpenAI and Codex product guidance.
- `skill-creator` and `skill-installer` — create or install skills.
- `plugin-creator` and `plugin-management` — create or manage Codex plugins.
- `sites`, `sites-remix`, `create-pet`, `pets`, and `update-pet` — optional
  plugin-provided capabilities, unrelated to the normal GoShipKit workflow.

This inventory is workstation-specific and can change as plugins are installed.
A new contributor may have a different set of connections and should install
only the skills needed for their work. Project rules that every contributor
needs remain in the tracked root `AGENTS.md`.

Restart Codex or begin a new turn after installing skills so they are discoverable.
