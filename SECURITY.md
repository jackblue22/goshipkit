# Security Policy

GoShipKit is pre-release software and does not yet publish supported security release lines.

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include affected versions or commit, reproduction steps, impact, and any known workaround. Do not include real user data or credentials.

Security-sensitive areas include authorization boundaries, invitation and share-link tokens, webhook signatures, stored provider credentials, resource visibility, and tenant scoping. Secrets must never be stored in plaintext or committed to the repository.
